# 保存姿态上的落地改进与具体缺口

本轮在现有冻结姿态上完成了一个有物理依据的规则改进：允许同一脚跟或脚尖成为整段支撑中的固定点，要求正常/镜像两路都支持同一解剖点。它处理落地后脚掌转动导致“脚跟和脚尖必须同时静止”漏检的问题。所有阈值保持不变，预测函数不读取人工标签；人工标签只用于开发问题定位和事后比较，没有用人工帧直接填预测。

| 同一 27 个可比较窗口 | 原整鞋规则 | 新固定点补充 |
| --- | ---: | ---: |
| 候选数 | 22 | 65 |
| 匹配人工列表项 | 13 | 41 |
| 未匹配预测 | 9 | 24 |
| 未匹配人工项 | 143 | 115 |
| 单评审列表精确率 | 59.1% | 63.1% |
| 单评审列表召回率 | 8.3% | 26.3% |
| 窗口内列表计数 MAE | 4.963 | 3.370 |

新方法在 23 段产生候选。原有 22 候选全部保留，另加 43 候选；7 个缺输入区间和 5 个解剖通道歧义事件继续未知。旧冻结基线不变，新实验单独保存。当前仍有明显漏检和误报，这是同批开发视频上的单评审诊断，不是独立测试准确率。

## 其他要求的实证缺口

| 要求 | 本轮已导出的证据 | 真正缺少的输入或验证 |
| --- | --- | --- |
| 连续俯视助跑轨迹 | 226 个触球前地面假设点；其中 120 点落在实际冻结助跑窗口，覆盖 31 段；CSV 逐点保留时钟、坐标假设及标定未验证标志 | 完整助跑图像、逐帧可信相机几何、连续且身份一致的地面接触点，以及独立标定误差。不能把稀疏点直接连线后称完整米制轨迹 |
| 严格门将高度 | 39 段失败原因表；16 段首扑姿态支撑不足、8 段缺可靠准备姿态脚踝/躯干等 | 从准备到落地不中断的门将动作、稳定地面及人体参照、相机标定。人工“低/中”不是米制高度 |
| 球最终位置 | 14 段在人框附近失踪，8 段片段边界前未见结束状态，5 段中途检测丢失，另 12 段身份/触球不支持 | 直到真实事件终点的原片，遮挡和切镜后的同一球身份及坐标关联。最后检测点不能替代事件最终位置 |
| 慢动作分类 | 320 个镜头区间；301 个尚无同动作对齐、19 个角色动作对齐证据不足 | 同一动作的正常速度和回放片段、稳定角色身份、足够连续动作变化以及可信实际时间参照；容器 FPS 不能决定播放速度 |
| 完整原片复现 | 当前包包含两段可哈希核验的 Rashford、Muriel 视频及全部已保存姿态回放输入 | 其余 37 段或完整四场授权课程录像，以及模型和提取依赖；不能从特征 JSON 恢复缺失像素 |
