# GitHub publish scope (2026-10-29)

This repository update keeps the code, configuration, report/PPT/video drafts, tests, final training audit summaries and small result tables needed for review.

The update deliberately excludes original match videos, model weights, ZIP archives, private chat attachments, personal-account data and large frame/crop exports. Those files are either ignored by `.gitignore` or remain documented as local/SharePoint inputs. The repository therefore provides a reviewable and partially reproducible project package, not a complete redistribution of the course media.

The final training artifacts are summaries and selection receipts only:

- `outputs/ball_final_augmentation_2026-10-29/release_review/`
- `outputs/keeper_detector_final_summary_2026-10-29/`
- `outputs/provisional_coverage_2026-10-29/`

The selected default pipeline is unchanged. Ball augmentation was not promoted, and the active-keeper control is a standalone experiment rather than an automatic replacement for the event/direction/height path. The strict height and event-final ball-position fields remain unknown where their evidence contracts are not satisfied.

Before official submission, the group must review the report, add member names/contributions and references, put the permitted course data and required code/data package on the course SharePoint location, and record the final ten-minute presentation in a student's natural voice.
