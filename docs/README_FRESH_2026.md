# Current Fresh Package

The repository contains a rerun of all 39 course penalty attempts. Start with [`final_bundle_v3_shoe_fusion`](../outputs/fresh_course_experiment/final_bundle_v3_shoe_fusion/), the [`final_eda_v3_shoe_fusion`](../outputs/fresh_course_experiment/final_eda_v3_shoe_fusion/) figures and [`REPORT_FRESH_REVIEW_DRAFT.md`](REPORT_FRESH_REVIEW_DRAFT.md). Previous bundles are retained as historical results.

The bundle has 33 independent contact candidates, 32 contact-bound phase candidates, 13 cautious striking-foot candidates, 1 conditional image-plane goalkeeper signal, 23 keeper direction candidates, 11 target camera candidates, zero automatic slow-motion decisions, 35 source-only scoreboard candidates and zero verified event-final ball positions. Five new foot candidates come from source-bound paired 33-landmark shoe evidence where V2 was unknown. Five former image-height categories were withdrawn because their fixed-depth reference failed; the numeric diagnostics remain available. These are development candidates with explicit unknowns, not human-verified accuracy. The scoreboard branch reads repeated red/green broadcast icons from original source frames; it is not ball-plane crossing evidence.

The 13 October strike-window replay and fresh rotated keeper-ROI pilot remain separate experiments. The former provides three newly covered right-channel hypotheses but abstains on the eight previous candidates. The latter repairs Kane's preparation reference but does not produce a complete-dive category. The guarded 33-landmark cohort and [selection protocol](SHOE_POSE33_FUSION_PROTOCOL_2026-10-13.md) provide the five fallback foot candidates. Additional official FIFA footage has been acquired, hashed and processed in a [three-event pilot](HD_PILOT_RESULTS_2026-10-13.md); it uses a distinct source clock and cannot reuse course-source caches or become new independent attempts.

The original nano and medium detector runs remain frozen. [`model_comparison_v1`](../outputs/fresh_course_experiment/model_comparison_v1/) records the controlled ablation, and [`ball_goal_guard_v4`](../outputs/fresh_course_experiment/ball_goal_guard_v4/) records the conservative keeper-occlusion reanalysis. The final bundle retains source, pose, producer and code hashes for every event.

Install the CPU analysis environment from [`requirements-experiments.txt`](../requirements-experiments.txt), and use [`requirements-cuda.txt`](../requirements-cuda.txt) only in an isolated Linux/CUDA environment. Run `python -m pytest -q` for the full contract suite. The exact experiment definitions and evaluation boundaries are in [`FRESH_EXPERIMENT_PROTOCOL.md`](FRESH_EXPERIMENT_PROTOCOL.md). The package is still a review draft; students must verify the code, report, video narration and contribution statements before official submission.
