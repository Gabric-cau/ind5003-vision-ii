## 实验与 4090

先冻结待检验方法、输入、参数、计数定义与评价指标，再决定 GPU 工作。4090 可用于较高分辨率检测、姿态对照、球轨迹重关联等实际耗时步骤；它不能补回没拍到的助跑、替代球场标定或产生独立真值。本改进包的汇总与 EDA 不需要 4090，当前也没有声称进行了新的 GPU 实验。

当前 39 条及其镜头均已用于开发或诊断，10 条脚参考也参与过方法挑选。不能事后换一个文件名就声称它们成为未接触测试集。后续留出应在调参前选择新的、未检查过的事件，或新的完整比赛，并把同一事件的所有镜头/回放归为同一组；当前结果只报告开发集描述性比较。
