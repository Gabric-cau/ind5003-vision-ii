# IND5003 submission review package

This archive is a review package for the group, not the official course submission.

It contains the current source code, configurations, tests, report draft, editable presentation draft, video outline, final training audit summaries, EDA figures and the 39-event saved-result table. The package is intended for group review and for preparing the final SharePoint submission.

It deliberately excludes original match videos, model weights, ZIP archives, private chat attachments and personal-account data. Raw footage and model files must be supplied through the permitted course/SharePoint route if the teaching team requires raw-to-feature reproduction.

Before submission, the group must:

1. Replace member placeholders and verify the contribution statement.
2. Check every number against the source tables and retain strict `unknown` values.
3. Add final references and a truthful AI-assistance disclosure.
4. Record the ten-minute presentation in a student's natural voice at normal playback speed.
5. Put the permitted code/data package on the course SharePoint location and complete the official submission and peer evaluation separately.

The final training comparison did not improve the default pipeline. Strict goalkeeper height and event-final ball position remain unknown where their evidence contracts are not satisfied. Provisional coverage values in the archive are observations, not accuracy.
