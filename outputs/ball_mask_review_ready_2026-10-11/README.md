# 球识别与连续关联优化验收

主入口：report.html。绿色是新版本选中的候选，蓝色是上轮候选，黄色是有效静止种子，橙色加号只表示预测。

本轮纳入39条规范片段，窗口与上轮保持一致，没有利用进球/没进球标签截掉尾段。窗口仍是自动触球前0.4秒到后2.3秒，并受主镜头结束限制；未覆盖全部原片、重复片段和重播。作业要求的球轨迹、最终位置及自动进球判定尚未全部完成。

## 改动

- 起点用亮色/低饱和度掩膜、绿色偏色限制与35像素脚附近范围，纠正草地杂点起点。
- 掩膜只影响种子候选；所有飞行神经候选保留，运动差分候选也保留。预测不加入检测轨迹。
- 起跑可在首次可见球已离罚球点较远时由连续候选回推；不会因原位置出现鞋而强行推迟真实起跑。
- 同时比较连续方向、预测残差与运动候选尺寸，降低细网格干扰的竞争力。
- 修复晚出生起跑假设覆盖已锁定早期轨迹的入口。至少5个候选支持后才冻结起跑段，短暂的杂点假设不会锁死真正的起跑。
- 高分、近圆形静止候选出现在回推起跑之后时，会否决不一致的起跑假设；使用触球前至少2帧的候选，避免触球时鞋干扰。
- 全局起跑速度门槛提高为每个原视频帧15像素，抑制慢速跑动衣服候选抢先锁定。39条使用同一门槛复测，不使用片段专属坐标或进球标签。Uribe 的早期球飞行段恢复，其余38条选中点未变；跨分辨率和慢速球未验证。

## 证据范围

视觉核对是助手对原视频像素的抽样核对，不是人工逐帧真值；只确认某一代表帧/飞行帧是否可见球，不保证整个片段全程正确。球门、扑救与反弹后的身份混淆仍有，不能把运行完整或单元检查当成准确率。accuracy_validated=false，human_verified=false，进球结果与最终位置仍unknown。

复用了上轮 fresh YOLO11n 推理的原始检测，以及从原视频新计算的像素掩膜、运动候选；本轮重新执行关联及同种子旧规则对照，没有重新运行神经模型。旧轨迹仅用于蓝色画面对照；没有手工输入球坐标，也没有读取进球结果标签。候选池、源文件、代码快照与媒体校验信息都在 protocol.json、inputs/、source_snapshot/ 和 validation.json。

## 复现

在项目根目录运行：

```powershell
& C:/Users/30605/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe -X utf8 -m scripts.run_ball_mask_continuity_review --output-dir outputs/ball_mask_reproduction_NEW --candidate-cache outputs/ball_mask_continuity_2026-10-11
```

输出目录需尚不存在。省略 --candidate-cache 会从上轮神经检测缓存重新计算像素掩膜与运动候选。运行自动验证两遍关联一致、每个选中点属于当前候选、候选池未被修改，并逐帧解码39个输出视频。

可用 scripts/build_ball_mask_review_evidence.py 生成原像素证据面板；visual_review.json/csv 是独立的助手视觉核对记录，未输入关联算法。53项检查覆盖旧/新连续关联约束、掩膜、晚出生覆盖、短假设锁死、跑动衣服抢先锁定、遮挡和预测分离。

association_refinement.json 记录最后一次对39条各运行两遍的关联复测；protocol_before_refinement.json 与代码快照保留全局起跑速度门槛调整前的来源。像素证据面板与最终视觉记录均在最终关联后生成。

本地文件浏览器访问受到工具限制；已检查HTML引用、图片格式和视频解码，浏览器按钮交互未通过工具实测。
